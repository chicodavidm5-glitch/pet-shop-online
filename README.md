# PET SHOP ONLINE

Tienda virtual demostrativa creada con HTML, CSS y JavaScript.

## Cómo abrir el proyecto
1. Descarga y descomprime `pet-shop-online.zip`.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en tu navegador (puedes usar la extensión Live Server).

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub.
2. Sube todos los archivos y la carpeta `assets`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda y espera la publicación.

## Importante
Este proyecto es una demostración frontend. Las cuentas, el carrito, los productos y pedidos se guardan en el almacenamiento local del navegador. No hay base de datos compartida, autenticación segura ni procesamiento real de pagos. Para una tienda real se necesita un backend, medidas de seguridad y una pasarela de pago. Las imágenes de productos se cargan desde Unsplash y requieren conexión a internet.
